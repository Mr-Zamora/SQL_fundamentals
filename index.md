## Getting Started

If you're new to SQL, we recommend following this sequence:

1. Read the [Setup Guide](https://github.com/Mr-Zamora/SQL_fundamentals/blob/master/setup/00_setup_guide.md) and install SQLite
2. Follow the core tutorial files in order (1-12)
3. Practice with the [Exercises](https://github.com/Mr-Zamora/SQL_fundamentals/blob/master/exercises/exercises.md)
4. Try the [Complete Example Script](https://github.com/Mr-Zamora/SQL_fundamentals/blob/master/examples/complete_example.py)
5. Explore a project from the [Project Ideas](https://github.com/Mr-Zamora/SQL_fundamentals/blob/master/resources/project_ideas.md)
