## Getting Started

If you're new to SQL, we recommend following this sequence:

1. Read the [Setup Guide](setup/00_setup_guide.md) and install SQLite
2. Follow the core tutorial files in order (1-12)
3. Practice with the [Exercises](exercises/exercises.md)
4. Try the [Complete Example Script](examples/complete_example.py)
5. Explore a project from the [Project Ideas](resources/project_ideas.md)
